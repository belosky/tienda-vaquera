# 🤠 El Ranchero Store

Página web estática para una tienda de ropa vaquera y western: botas, sombreros, cintos y camisas. Hecha solo con HTML, CSS y JavaScript, sin frameworks ni dependencias.

## Estructura

```
/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── assets/
│   └── .gitkeep
└── README.md
```

## Personalización rápida

Antes de publicar, cambia estos datos marcadores:

- **Nombre de la tienda:** busca `El Ranchero Store` en `index.html` y `README.md`.
- **Correo:** reemplaza `tu-correo@ejemplo.com` en `index.html`.
- **WhatsApp:** reemplaza `50200000000` (código de país + número) en `index.html` y en `js/main.js`.
- **Redes sociales:** actualiza los enlaces del pie de página en `index.html`.
- **Colores:** edita las variables al inicio de `css/styles.css` (`:root`).

## Ver el proyecto en local

Abre `index.html` con doble clic en tu navegador, o con la extensión Live Server de VS Code.

## Clonar el repositorio

```bash
git clone https://github.com/TU-USUARIO/el-ranchero-store.git
cd el-ranchero-store
```

## Subirlo a GitHub y publicarlo con GitHub Pages

1. Crea un repositorio vacío en GitHub llamado `el-ranchero-store`.
2. Desde la carpeta del proyecto:

```bash
git init
git add .
git commit -m "Primer commit: estructura de El Ranchero Store"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/el-ranchero-store.git
git push -u origin main
```

3. En GitHub ve a **Settings → Pages**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`, y guarda.
4. Tu sitio quedará en `https://TU-USUARIO.github.io/el-ranchero-store/`.
